# Comma Smart School | منصة كوما للتعليم الذكي (PWA)

بروتوتايب تفاعلي متقدم لمنصة إدارة المدارس والطلاب **Comma Smart School**، مستوحى بالكامل من تصميم التطبيق الأصيل (Mobile-First) المتوافق مع شاشات الجوال والويب، مع دعم كامل للتحميل والتثبيت كـ **تطبيق PWA (Progressive Web App)** على هواتف **iPhone (iOS)** وأجهزة **Android**.

---

## 📱 المميزات الرئيسية

### 1. تصميم جوال أصيل (Native iOS Feel)
- **شاشة رئيسية ولوحة تحكم (Dashboard)** مطابقة للصور:
  - ترويسة أنيقة باللون الأزرق الملكي باسم المدرسة وحساب مدير النظام.
  - شبكة العدادات السريعة (35 طالباً، 0 معلمين، 6 فصول، 9 أولياء أمور، 2 أقسام، 0 مشاكل).
  - بطاقة **الإحاطة التشغيلية 📂** (تغطية البدلاء المعلقة وعناصر سير العمل المفتوحة مع إمكانية فتح التفاصيل واعتماد البدلاء).
  - شريط تنبيهات المؤشرات (الطلاب في خطر، المواد الدراسية، السجلات المطلوبة، الروابط المفقودة).
  - شبكة **أدوات مدير النظام 💻** ببطاقات ملونة ذات تدرجات لونية عصرية وأيقونات ثلاثية الأبعاد (نظرة إعداد المدرسة، إدارة الطلاب، أولياء الأمور، المعلمون والطاقم، الصفوف والشعب، الأقسام والمواد، بناء الجدول، الصلاحيات، سلامة البيانات، إعدادات المدرسة).

### 2. إدارة الطلاب (Students Management)
- شريط إحصائي متكامل (إجمالي الطلاب، النشطين، الحلقات الناقصة، بلا ولي أمر، بلا فصل).
- شريط بحث فوري ذكي بالاسم أو الرقم أو الفصل.
- تصنيفات وفلاتر سريعة (الكل، المشاكل فقط، بلا ولي أمر، ملف غير مكتمل، نشط، غير نشط).
- بطاقات تفصيلية للطلاب مع وسوم الحالة الصحية، ارتباط ولي الأمر، واكتمال الملف.
- إمكانية فتح **الملف الشامل للطالب** في نافذة سفلية (Bottom Sheet) لاستعراض المعدل، الحضور، بيانات ولي الأمر، والحالة الصحية واعتمادها فورياً.
- زر **إضافة طالب جديد** مع نموذج حفظ وتسكين فوري وتحديث العدادات.
- ميزة **تصدير واستيراد البيانات** (JSON / CSV).

### 3. إدارة المعلمين والمستخدمين (Staff & Users)
- إحصائيات الطاقم (المعلمون، الإداريون، أولياء الأمور).
- بطاقات المستخدمين بالاسم العربي والإنجليزي والمسمى الوظيفي وحالة النشاط.
- إمكانية إضافة مستخدم/معلم جديد وتفعيل صلاحياته.

### 4. الصفوف والشعب (Classes & Sections)
- استعراض الفصول الدراسية (10-A, 10-B, 9-A, 9-B, 9-C, 11-A) وسعة كل فصل ونسبة الإشغال ورائد الفصل.

### 5. شريط تنقل سفلي زجاجي عائم (Floating Frosted Glass Bottom Bar)
- مستوحى من واجهات iOS الحديثة بتأثير بلور زجاجي، مع تمييز التبويب النشط بالكبسولة الملونة المطابقة للصور.

### 6. وضعين للعرض (Dual View Mode)
- **وضع الجوال (iPhone Frame)**: استعراض التطبيق داخل إطار هاتف iPhone 16 Pro أنيق مع الجزيرة التفاعلية (Dynamic Island) وأزرار التحكم.
- **وضع الويب الشامل (Full Screen Responsive)**: التبديل بنقرة زر لعرض لوحة تحكم كاملة الشاشة متجاوبة مع الحواسيب والشاشات الكبيرة.
- **عند فتح الرابط على الجوال الحقيقي**: يتحول التطبيق تلقائياً وبشكل أصيل إلى ملء الشاشة بنسبة 100% بدون أي إطارات إضافية.

## 📲 كيفية تثبيت التطبيق كـ PWA على الجوال

### 🍏 على هواتف آيفون (iPhone - iOS Safari):
1. افتح رابط التطبيق في متصفح **سفاري (Safari)**.
2. اضغط على زر المشاركة بالأسفل **(Share / ⎋)**.
3. مرر لأسفل واختر **«إضافة إلى الشاشة الرئيسية» (Add to Home Screen)**.
4. اضغط **إضافة (Add)**.
5. سيظهر التطبيق على شاشة هاتفك الرئيسية بأيقونة Comma Edu المستقلة، ويعمل بشاشة كاملة وبدون شريط عنوان المتصفح!

### 🤖 على أجهزة أندرويد (Android - Chrome):
1. افتح الرابط في متصفح **Chrome**.
2. ستظهر لك رسالة تلقائية أو يمكنك الضغط على خيارات المتصفح (⋮).
3. اختر **«تثبيت التطبيق» (Install App)**.

## 🚀 كيفية تشغيل المشروع محلياً

المشروع مبني بتقنيات الويب القياسية الصرفة (HTML5, Vanilla CSS3, Modern JS) بدون الحاجة لأي عمليات بناء معقدة:

```bash
# تشغيل خادم محلي سريع
npx serve -l 4173

# أو باستخدام Python
python -m http.server 4173
```
ثم فتح: `http://localhost:4173/` في أي متصفح.
